# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

---

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3293 - [LEARNING LOGS] BigFrame
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
667031
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
15-30 minutes
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้รับข้อความ 5 บรรทัดจากผู้ใช้ (แต่ละบรรทัดอาจว่างหรือยาวไม่เท่ากันก็ได้ มีแค่ a-z, A-Z, 0-9 และเว้นวรรค) แล้วนำมาใส่กรอบสี่เหลี่ยมที่ทำจากเครื่องหมาย * โดยจัดข้อความชิดซ้าย เติม space ด้านขวาให้เท่ากับความยาวบรรทัดที่ยาวที่สุด และเว้น space คั่นระหว่างกรอบกับข้อความฝั่งละ 1 ช่องเสมอ

ผลลัพธ์ต้องมี 7 บรรทัด คือเส้นกรอบบน 1 บรรทัด, ข้อความ 5 บรรทัด (แต่ละบรรทัดครอบด้วย * ซ้าย-ขวา), และเส้นกรอบล่าง 1 บรรทัด กรอบซ้ายกับขวาต้องห่างกันอย่างน้อย 2 space แม้ข้อความทุกบรรทัดจะว่างเปล่าก็ตาม

จุดที่ต้องระวังคือช่องว่างท้ายบรรทัดที่ติดมากับอินพุตไม่ควรนับเป็นความยาวข้อความจริง และโค้ดตัวอย่างมีปัญหา indentation ที่ควรเช็กก่อนส่ง
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
ขั้นแรกคือต้องรับ input เข้ามา 5 บรรทัดก่อน เก็บใส่ list ไว้ แต่ต้องระวังเรื่อง space หรือ newline ที่อาจติดท้ายบรรทัดมาด้วย เพราะถ้าไม่ตัดออกจะทำให้คำนวณความยาวข้อความผิดได้

จากนั้นต้องหาว่าบรรทัดไหนยาวที่สุดในทั้ง 5 บรรทัด เพราะความยาวนี้แหละที่จะใช้เป็นตัวกำหนดความกว้างของกรอบ ทุกบรรทัดจะถูก pad ด้วย space ด้านขวาให้ยาวเท่ากับบรรทัดที่ยาวที่สุดนี้ เพื่อให้กรอบด้านขวาตรงกันหมด
พอรู้ความกว้างแล้ว ก็เอาไปสร้างเส้นกรอบบนกับล่าง โดยความยาวของเส้นกรอบจะเท่ากับ (ความกว้างข้อความ + 4) เพราะต้องบวกเผื่อ space ซ้าย 1 ช่อง ดอกจันซ้าย 1 ตัว ดอกจันขวา 1 ตัว และ space ขวา 1 ช่อง

หลังจากนั้นก็ print เส้นกรอบบนออกไปก่อน แล้ววนลูปพิมพ์ทีละบรรทัดในรูปแบบ ดอกจัน-เว้นวรรค-ข้อความ(ที่ pad แล้ว)-เว้นวรรค-ดอกจัน จนครบ 5 บรรทัด สุดท้ายก็ print เส้นกรอบล่างปิดท้ายอีกที รวมแล้วจะได้ output ออกมา 7 บรรทัดพอดี

มีจุดที่กังวลอยู่นิดหน่อยคือกรณีที่ทุกบรรทัดว่างเปล่าไปเลย (ไม่มีตัวอักษรอะไรเลย) แบบนี้กรอบจะยังห่างกันครบ 2 space ตามที่โจทย์บอกไหม เดี๋ยวต้องลองรันเช็คดูอีกที และอีกจุดคือต้องระวังเรื่อง indent ของโค้ดให้ถูก ไม่งั้นโปรแกรมจะรันไม่ผ่าน

```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีที่ใช้จริงก็เหมือนกับแผนแรกที่วางไว้เลย ไม่ได้เปลี่ยนแนวคิดอะไร เพราะพอลองไล่ดูตามขั้นตอนแล้วมันตรงโจทย์อยู่แล้ว คือ อ่าน input 5 บรรทัดเก็บไว้ในลิสต์ หาความยาวของบรรทัดที่ยาวที่สุดมาเป็นตัวกำหนด width จากนั้นสร้างเส้นกรอบด้วยดอกจันความยาว width+4 แล้ว print กรอบบน วนลูป print ข้อความแต่ละบรรทัดที่ถูก pad ด้วย space ด้านขวาให้เท่ากับ width โดยมี * คั่นด้านซ้ายกับ * คั่นด้านขวาเสมอ และปิดท้ายด้วยกรอบล่างอีกที

เหตุผลที่ใช้วิธีนี้เหมือนเดิมก็เพราะมันตรงไปตรงมาและครอบคลุมทุกเงื่อนไขที่โจทย์ต้องการอยู่แล้ว ไม่ต้องมี logic ซับซ้อนอะไรเพิ่ม แค่ต้องแก้จุดที่พลาดไปตอนแรกคือเรื่อง indentation ของ loop ที่ไม่ถูก และปรับการตัด trailing space ตอนรับ input ให้รอบคอบขึ้น เพื่อไม่ให้ความยาวข้อความคลาดเคลื่อน

```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text
No
```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
