# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์นี้มีฝูงแมวกับจิ้งจอก แต่ละตัวมีชื่อกับหมายเลข (เช่น Cat06, Fox02) ผมต้องนับว่ามีแมวกี่ตัว จิ้งจอกกี่ตัว แล้วแสดงชื่อพร้อมหมายเลขเรียงตามหมายเลข โดยแสดงแมวก่อนแล้วตามด้วยจิ้งจอก ส่วนที่ต้องระวังคือโดยปกติในฝูงจะมี Garfield (Cat01) กับ Fubuki (Fox01) อยู่แล้ว ถ้าข้อมูลที่ให้มาไม่มี Cat01 หรือ Fox01 ผมต้องเติมสองตัวนี้เข้าไปเองด้วย

Input บรรทัดแรกคือจำนวน n จากนั้นอีก n บรรทัด แต่ละบรรทัดเป็น dict หนึ่งอัน เช่น {“Chi” : “Cat06”} โดย key คือชื่อ value คือหมายเลข Output บรรทัดแรกคือ Cat : จำนวนแมว บรรทัดที่สองคือ Fox : จำนวนจิ้งจอก แล้วตามด้วยรายชื่อในรูปแบบ ชื่อ : หมายเลข ส่วน constraints ที่สำคัญคือชื่อกับหมายเลขจะไม่ซ้ำกัน และโจทย์อยากให้ใช้ dict กับ dict methods
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
ตอนแรกผมคิดว่าจะอ่านแต่ละบรรทัดแล้วแปลงข้อความให้กลายเป็น dict จากนั้นเอามารวมเก็บไว้ใน dict ตัวเดียว หลังอ่านครบก็เช็คว่ามี Cat01 กับ Fox01 หรือยัง ถ้ายังไม่มีก็ใส่ Garfield กับ Fubuki เข้าไป แล้วค่อยแยกว่าตัวไหนเป็นแมวตัวไหนเป็นจิ้งจอก โดยดูจากตัวอักษรนำหน้าของหมายเลข สุดท้ายเรียงตามเลขท้ายแล้วพิมพ์ผล

pseudocode ที่คิดไว้คือ อ่าน n แล้ววนอ่านข้อมูลทีละบรรทัดเก็บรวมใน dict จากนั้นเช็ค Cat01 กับ Fox01 ถ้าไม่มีก็เติม แล้วแยกเป็นลิสต์แมวกับลิสต์จิ้งจอก เรียงแต่ละลิสต์ตามตัวเลขในหมายเลข พิมพ์จำนวนแมว จำนวนจิ้งจอก แล้วพิมพ์รายชื่อของแมวตามด้วยจิ้งจอก
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายเหมือนแผนแรกเลยครับ ผมใช้ ast.literal_eval แปลงข้อความแต่ละบรรทัดให้เป็น dict แล้วเอามารวมใน dict ชื่อ herd โดยใช้ชื่อเป็น key และหมายเลขเป็น value ต่อมาผมเก็บหมายเลขทั้งหมดไว้ใน set ชื่อ used_codes เพื่อเช็คว่ามี Cat01 กับ Fox01 อยู่แล้วหรือไม่ ถ้าไม่มีและชื่อ Garfield หรือ Fubuki ก็ยังไม่ถูกใช้ ผมจะเติมเข้าไป เหตุผลที่เช็คชื่อด้วยก็เพราะโจทย์บอกว่าชื่อจะไม่ซ้ำ

จากนั้นผมแยกเป็นลิสต์ของแมวกับจิ้งจอก โดยดูว่าหมายเลขขึ้นต้นด้วย Cat หรือ Fox เก็บเป็นคู่ (หมายเลข, ชื่อ) แล้วเรียงด้วยตัวเลขที่ตัดจากหมายเลข (ใช้ int(item[0][3:])) เหตุที่แปลงเป็นตัวเลขก่อนเรียงเพราะไม่อยากให้เรียงผิดแบบตัวอักษร สุดท้ายพิมพ์จำนวนและรายชื่อตามรูปแบบที่โจทย์กำหนด
```

## 5. การทดสอบของฉัน

เขียน test cases อย่างน้อย 3 กรณีที่ลองเองหรือออกแบบเอง

พยายามเลือก test cases ที่แตกต่างกัน

แต่ละ test case ให้อธิบายว่าทำไมเลือกกรณีนั้น

ถ้า input หรือ output มีหลายบรรทัด ให้เขียนไว้ใน text blocks

### Test Case 1

ทำไมเลือก case นี้:

```text
ผมเลือกเคสนี้เพราะเป็นเคสหลักที่ต้องเติมทั้ง Garfield และ Fubuki และต้องเรียงลำดับให้ถูกด้วย
```

```text
n=5 ข้อมูลคือ Chi : Cat06, Tom : Cat05, Shiro : Fox02, Senko : Fox10, Chocola : Cat03
```

```text
Cat : 4, Fox : 3 แล้วตามด้วย Garfield : Cat01, Chocola : Cat03, Tom : Cat05, Chi : Cat06, Fubuki : Fox01, Shiro : Fox02, Senko : Fox10
```

```text
Cat : 4, Fox : 3 แล้วตามด้วย Garfield : Cat01, Chocola : Cat03, Tom : Cat05, Chi : Cat06, Fubuki : Fox01, Shiro : Fox02, Senko : Fox10
```

Result:

```text
Pass
```

## 6. การใช้ AI

```text
No
```

ถ้าใช้ AI ต้องทำไฟล์นี้ด้วย:

```text
ai_reflection.md
```

ถ้าถามเฉพาะเพื่อน TA หรือผู้สอน และไม่ได้ใช้ AI ไม่ต้องทำ `ai_reflection.md`

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่


ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
